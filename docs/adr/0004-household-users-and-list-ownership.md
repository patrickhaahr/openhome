# Household users own wishlists and watchlists

The shared Dashboard uses one household view without a global profile selector.
Configurable Household Users appear together inside Wishlist and Watchlist;
lists are visible to all household members and editing targets the list's owner.
Ownership applies to new Wishlists and Watchlists, while existing
fitness and integration data retains its current ownership. We chose this
trusted-household model over introducing authenticated private accounts and
retrofitting all existing data, keeping shared-display use simple and existing
clients compatible. Household ownership is not a privacy or authorization boundary.
